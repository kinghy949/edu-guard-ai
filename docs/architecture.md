# 架构说明

## 总体架构

单体架构，前后端分离，后端内聚业务模块；通过水平拆分包结构保持可演进性。

```
[Vue3 SPA]  ──REST/JSON──▶  [FastAPI 单体服务]  ──SQL──▶  [PostgreSQL]
                                  │
                                  ├─▶ LLM Provider (OpenAI 兼容)
                                  ├─▶ SMTP
                                  ├─▶ 企业微信 / 钉钉 Webhook
                                  └─▶ 短信网关
```

## 后端模块

| 模块 | 目录 | 职责 |
| --- | --- | --- |
| API 层 | `app/api/v1` | REST 路由，依赖注入鉴权 |
| 业务服务 | `app/services` | 培养方案比对、预警生成、通知分发、导入导出 |
| AI 服务 | `app/ai` | LLM 客户端封装、学业问答 Prompt、RAG |
| 数据层 | `app/models`, `app/schemas` | ORM 与 DTO |
| 通知适配 | `app/notifiers` | email / wecom / dingtalk / sms |
| 核心 | `app/core` | 配置、数据库会话、安全、调度 |

## 关键流程

### 1. 学业完成度计算

```
学生 ─▶ 所属培养方案 ─▶ 各学分桶（必修/限选/任选/通识/实践）
                       │
                       └─▶ 已修课程按桶累加 ─▶ 缺口 = 要求 - 已修 - 在修
```

### 2. 预警生成

调度任务（每学期末 / 手动触发）：
1. 拉取目标学生集合
2. 调用比对引擎计算缺口
3. 按规则评级：`提示 / 警告 / 严重`
4. 写入预警表 + 触发通知中心

### 3. AI 学业问答

```
用户问题 ─▶ 上下文构造（学生 ID → 培养方案 + 已修课程 + 缺口）
       ─▶ 拼接系统 Prompt + 用户问题
       ─▶ LLM 推理
       ─▶ 流式返回前端
```

## 角色与权限

| 角色 | 权限 |
| --- | --- |
| 学生 | 查看本人完成度、预警、AI 问答 |
| 辅导员/班主任 | 查看本班学生、批量导入、触发预警、通知配置 |
| 教学管理员 | 培养方案管理、用户管理、系统配置 |
