# 路线图

## M0 · 仓库初始化（已完成）
- 架构文档、目录骨架、docker-compose、README

## M1 · 数据底座
- 数据模型 + Alembic 迁移
- 用户、培养方案、课程、成绩 CRUD
- CSV/Excel 批量导入（学生名册、培养方案、成绩单）
- JWT 登录、角色权限

## M2 · 比对引擎与预警
- 学分桶累计算法
- 缺口计算与"推荐补修课程"候选
- 预警规则配置（按阶段、按分类阈值）
- 调度任务（手动 + 定时）

## M3 · 通知中心
- 适配器：邮件 / 企业微信 / 钉钉 / 短信
- 通知模板（Jinja2），变量注入
- 通道开关与失败重试
- 通知历史

## M4 · AI 学业问答
- LLM 客户端（OpenAI 兼容协议）
- 学生上下文拼装（培养方案 + 缺口 + 已修）
- 流式响应、会话历史
- 安全策略（敏感信息脱敏）

## M5 · 管理后台与部署
- 管理员后台（用户、培养方案、规则、通道配置）
- 操作审计日志
- 部署文档（docker-compose / k8s）
- 备份与恢复
